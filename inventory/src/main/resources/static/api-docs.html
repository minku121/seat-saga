Inventory Service
🔒 Admin JWT Secured (secret: admin-key)

SeatSaga API Reference

Complete catalog of Inventory endpoints. Public APIs allow browsing events and seat types without auth. Admin APIs manage events and seat inventories and require a valid JWT signed with admin-key.

Base URL: http://localhost:8082
JWT Header: Authorization: Bearer <token>
Admin Secret: admin-key
💡
How to authenticate admin requests: Call POST /api/admin/token with {"secret": "admin-key"} to receive a 24-hour Bearer token. Include it on all /api/admin/** endpoints via Authorization: Bearer <token>.
